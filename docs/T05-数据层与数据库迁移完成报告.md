# T05 数据层与数据库迁移完成报告

完成日期：2026-10-17。对应编码计划T05，不包含后续任务的业务功能。

## 已完成

- 建立31个SQLAlchemy实体和2步Alembic迁移，覆盖目录、原始资料、识别候选、正式报价、不可变修订、应用、数据集版本、快照、模板、导出、审计和任务租约字段。
- 目的地只持有一个航线外键，标准身份和父港/码头键唯一；同港可以有多条报价，不建立港口唯一价。
- 金额使用SQLite缩放整数和ORM Decimal转换，保留NULL及明确零价，拒绝浮点数、负价、超精度；有效期存完整DATE并检查先后和日历有效性。
- 正式报价当前修订必须属于自身，修订关联同起运港应用；旧修订、快照、应用结果、模板版本和审计事件由触发器防止更新及删除。
- 建立乐观版本字段、数据集比较更新和同事务快照工具；应用幂等键、快照版本唯一，应用不能脱离对应快照单独提交。
- 已审私有码按命名空间/供应方/有效期排重；证据引用的批次一致性有检查。
- 显式升级命令支持新库初始化、旧修订升级、升级前一致性备份和失败回滚。禁止对未知旧库盲目初始化及破坏性降级。
- 健康接口只读返回真实结构状态；共享Python合同、JSON Schema、TypeScript和OpenAPI同步。网页仍明确正式报价未接入。
- 提供[数据库设计与迁移说明](T05-数据库设计与迁移说明.md)，包含字段含义、事务边界、命令、备份恢复、已实现范围和后续接入约定。
