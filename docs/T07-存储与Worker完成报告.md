# T07 存储与Worker完成报告

完成日期：2026-10-17。对应T07，详细实现和操作方式见[文件存储与后台任务说明](T07-文件存储与后台任务说明.md)。

## 已完成

- 私有Storage接口及本机实现：分块限额、SHA256、严格存储键、Windows junction/符号链接防逃逸、完整临时文件验证、原子发布且不覆盖原件或旧导出。
- 持久队列与同事务入队，幂等键/请求内容核对；相同请求只登记一个任务，不用进程内回调假装队列。
- 独立Worker、primary单例租约、每次执行的新fencing token及独立心跳线程，长I/O时仍保持租约；旧Worker不能提交迟到结果。
- 保留每次attempt、不可变成功检查点及重试链；有限指数退避和抖动、Retry-After、永久错误直接失败。
- 排队取消、活动任务协作取消、租约过期中断恢复；强制终止不记成功，显式重试建立新任务并复用成功部分。
- 任务状态、取消、重试HTTP接口，要求本机会话及写请求Origin/CSRF，返回真实进度，不暴露payload、原异常、密钥、路径和内部结果引用。
- 新增0003_jobs增量迁移，34个业务表、26个保护触发器；旧数据和旧迁移保留，升级前备份。
- 本机可运行VERIFY_FILE处理器、诊断入队命令、Worker启动脚本、配置示例及同步生成的共享合同。
